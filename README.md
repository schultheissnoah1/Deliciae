# Deliciae

This repository contains the source for the [Deliciae website](https://schultheissnoah1.github.io/Deliciae/). Site files live in `site/`.

## Pull request previews

For a pull request targeting `main` from a branch in this repository, use **Open the GitHub Pages preview** in the pull request description. The preview is public and becomes available after deployment. It is removed after the pull request closes and the next deployment succeeds.
