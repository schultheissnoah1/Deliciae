# Repository instructions for agents

- For every repository change you make, use a feature branch, push it, and open a pull request against `main`.
- Add the GitHub Pages preview URL to the pull request description. The URL is `https://schultheissnoah1.github.io/Deliciae/previews/pr-<number>/`.
- Wait for the Pages deployment and check that the preview is reachable. Share the pull request and preview links with the user, and explicitly ask them to verify the preview before merging. If deployment fails, report the failure and keep the pull request open.
